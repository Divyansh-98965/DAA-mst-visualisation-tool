Spanning Tree Foundations

Before finding a Minimum Spanning Tree (MST), you must first master what constitutes a valid Spanning Tree. A spanning tree is a connected, acyclic subgraph containing every vertex of the original graph connected by the exact minimum number of edges.

Calculated by constructing the Laplacian matrix L = D − A, crossing out row & column vn to obtain reduced cofactor matrix L*, and evaluating τ(G) = det(L*) via Gaussian elimination.

1. Degree Matrix (D) Diagonal = Vertex Degree, Off-diag = 0
2. Adjacency Matrix (A) Aij = 1 if edge (i,j) exists, else 0
3. Laplacian Matrix (L = D − A) Lii = deg(vi), Lij = −1 if edge

Step-by-Step Linear Algebra Walkthrough:

  1. Graph Topology: Total vertices |V| = 5, Total edges |E| = 6.
  2. Laplacian Formulation: L = D − A is symmetric with row sums equal to 0.
  3. Cofactor Reduction: Delete row 5 and column 5 (Node E) to form the (n-1)×(n-1) cofactor matrix L*.
  4. Determinant Computation: Apply Gaussian elimination with partial pivoting to compute det(L*) = 11.

Kruskal's Algorithm Pseudocode 
function Kruskal(G=(V,E)):
  T = ∅, DSU = MakeSet(V)
  Sort E in non-decreasing weight order
  for each edge (u, v) ∈ E (sorted):
    if DSU.Find(u) ≠ DSU.Find(v):
      T = T ∪ {(u, v)}
      DSU.Union(u, v)
    else:
      // Cycle detected: discard edge
      discard (u, v)
  return T
Prim's Algorithm Pseudocode 
function Prim(G=(V,E), s):
  T = ∅, S = {s}
  PQ = MinPriorityQueue(edges from s)
  while |S| < |V| and PQ not empty:
    (u, v) = PQ.ExtractMin()
    if v ∉ S:
      S = S ∪ {v}
      T = T ∪ {(u, v)}
      for each edge (v, w) with w ∉ S:
        PQ.Insert((v, w))
  return T
